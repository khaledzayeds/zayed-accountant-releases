# Zayed Accountant

Windows desktop accounting application from ZayedX.

## Download

[Download Zayed Accountant 2.4.0 for Windows x64](https://github.com/khaledzayeds/zayed-accountant-releases/releases/download/v2.4.0/ZayedAccountant-Windows-2.4.0.zip)

Extract the complete ZIP, then run `ZayedAccountant.exe`. Keep the `api` and `data` folders beside the executable.

The package is a portable Windows release candidate built on August 22, 2026. Its launcher still reports version `2.2.0+3`; release `2.4.0` identifies the updated application and API payloads.

## Release 2.4.0

- Item transaction activity and posting account labels.
- Carton cost calculation and profit visibility.
- Payment item defaults and sales total adjustments.
- Arabic thermal payment method rendering.

Back up existing company files before using this release. Production printer acceptance remains to be completed.
